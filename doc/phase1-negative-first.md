# Phase 1 Negative-First validation

The reproducible absence workloads are generated by
`negative_first_absent_fixtures_finish_in_stage_b` in `src/png.rs`:

| Workload | Generated shape | Stage result | IDAT header probes |
|---|---|---:|---:|
| Screenshot-like | 1,024 one-byte IDAT chunks | Stage B resolved | 1,024 |
| Canvas-like | One 1 KiB IDAT chunk | Stage B resolved | 1 |
| Photo-like | One 3 MiB IDAT chunk | Stage B resolved | 1 |

All three contain no metadata. The test observed 3/3 Stage B resolutions and
0/3 Stage C escalations. The generated fixture code is the source of truth for
these results; they are stage-path measurements, not wall-clock performance
measurements.

Phase 0's five CLI goldens were also run against the Phase 1 implementation:
all five passed. The ComfyUI golden retains its legacy scan notice and output.
